# Sophro – Site de Karine Roman, Sophrologue

Site professionnel de Karine Roman, sophrologue certifiée à Brive-la-Gaillarde (Corrèze).

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Page d'accueil avec hero section, services, témoignages et blog |
| `services.html` | Services détaillés, tarifs et FAQ |
| `about.html` | Présentation de Karine Roman, formations et approche |
| `contact.html` | Formulaire de contact Formspree et informations |
| `blog.html` | Articles sur la sophrologie et le bien-être |

## Technologies

- **HTML5** sémantique avec ARIA pour l'accessibilité
- **CSS3** moderne : variables CSS, Flexbox, Grid, animations
- **Google Fonts** : Playfair Display + Lato
- **Images** : Unsplash (libres de droits)
- **Formulaire** : Formspree (compatible GitHub Pages)
- **JavaScript** vanilla (menu mobile, scroll, animations)

## Déploiement GitHub Pages

1. Aller dans Settings → Pages
2. Sélectionner la branche `main` (ou `master`)
3. Le site sera disponible à : `https://DISYP.github.io/Sophro/`

## Configuration Formspree

Pour activer le formulaire de contact :
1. Créer un compte sur [formspree.io](https://formspree.io)
2. Créer un formulaire et récupérer l'endpoint
3. Remplacer `https://formspree.io/f/xdoqpbwj` dans `contact.html`
